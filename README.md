# جدول المعلم

مصمم خلفية الجدول: تطبيق ويب عربي (RTL، Mobile-first، قابل للتثبيت) يقرأ **صورة** الجدول المدرسي على الجهاز ويحوّلها إلى خلفية جوال أنيقة (١٢٠٠×٢٦٠٠) أو جدول أفقي (١٩٢٠×١٢٨٠) بصيغة PNG.

رحلة المستخدم: صوّر جدولك أو اختر صورته → قراءة على الجهاز → **مراجعة الجدول المقروء** وتعديل أي خانة → اعتماد → اجعله على ذوقك (اسم المعلم، العنوان، طابع أخضر/ليلي/أبيض، مساحة للساعة، إظهار المادة، لون لكل فصل) → معاينة حية → حفظ الصورة أو مشاركتها. يُحفظ التصميم محليًا لتعود إليه لاحقًا.

إلى جانب الصورة، يمكن استيراد الجدول من منصة مدرستي دون أي بيانات دخول: إما بزر «جدولي» (إشارة مرجعية تعمل داخل جلسة المعلم في المتصفح وتنقل جدول الصفحة إلى التطبيق)، أو بنسخ صفحة الجدول ولصقها في التطبيق. `npm run e2e:madrasati` يختبر المسارين.

الموقع منشور على: https://alazm1.github.io/azzam/

تتم القراءة كاملة داخل المتصفح؛ الصورة لا تُرسل إلى أي خادم ولا يُحتفظ بها بعد الاستخراج.

## التشغيل

```bash
npm install          # ينسخ أيضًا محرك Tesseract إلى public/tesseract
npm run dev          # خادم التطوير
npm run build        # بناء الإنتاج (PWA) في dist/
npm run preview
```

## الاختبارات

```bash
npm test             # اختبارات الوحدة للمحلل + اختبارات المحرك على صور الجداول الثمانية
npm run fixtures     # إعادة توليد صور الاختبار (Chromium + خطوط عربية حقيقية)
npm run bench        # جدول دقة مفصّل لكل حالة (VERBOSE=1 لعرض قراءة كل خلية)
npm run e2e          # اختبار متصفح كامل على نسخة الإنتاج مع لقطات شاشة في tests/output
```

حالات الاختبار (`tests/fixtures`): جدول مدرستي، جدول أبيض وأسود، جدول ملون، الأيام في الصفوف، الأيام في الأعمدة، صورة بزاوية، جودة متوسطة (JPEG مضغوط ومموّه)، خلايا مدمجة وفارغة، بالإضافة إلى صورة مقلوبة ١٨٠° وصورة بلا جدول. الدقة الحالية على الحالات الثمانية ≈ ٩٩٪ في المتوسط.

## بنية المشروع

```
src/engine/                 محرك الاستخراج (مستقل عن الواجهة، يعمل في المتصفح وفي Node)
  image/preprocessor.ts     تجهيز الصورة: تباين، ثنائية تكيفية، معالجة المناطق الداكنة، اكتشاف رباعي الجدول وتصحيح الميل/المنظور
  image/tableDetector.ts    اكتشاف الخطوط الأفقية والرأسية، بناء الشبكة، الخلايا المدمجة، بديل بالإسقاط للجداول بلا حدود
  ocr/ocrService.ts         واجهة OCR مجردة + تنفيذ Tesseract.js (عربي، يعمل من أصول محلية)
  ocr/glyphClassifier.ts    متعرّف قوالب متخصص للتسميات القصيرة (٢/ب، ٤…) حيث يضعف الـ OCR العام
  parse/classify.ts         تصنيف كل خلية: يوم / حصة / حصة دراسية (فصل + مادة) / أخرى
  parse/scheduleParser.ts   فهم الجدول: محور الأيام ومحور الحصص، الاتجاه، الاستنتاج من الجوار، الخلايا المدمجة
  parse/scheduleValidator.ts التحقق، توحيد أسماء الفصول، درجة الجودة ورسالة الفشل
  pipeline.ts               التسلسل الكامل مع تقدم القراءة، ومحاولة الدوران عند الفشل
src/components/             الواجهة (ImportCard, PreviewPanel, SettingsPanel, EditDialog, ExportDialog…)
src/services/wallpaper.ts   رسم الخلفية على Canvas (الطوابع، المقاسات، ألوان الفصول)
src/services/importer.ts    تحويل نتائج المحرك إلى شبكة الحصص ودمج عدة صور
src/services/designStorage.ts  الحفظ المحلي للتصميم (قابل للاستبدال بـ Supabase لاحقًا)
src/models/design.ts        نموذج البيانات: الشبكة (حصص × أيام) وإعدادات التصميم
tests/                      اختبارات vitest + الصور المرجعية ونصوصها الصحيحة
scripts/                    توليد الصور المرجعية، الأطلس، الأيقونات، المقارنة، اختبار المتصفح
```

## كيف يقرأ المحرك الصورة

1. **تجهيز الصورة**: تحويل رمادي، تمديد التباين، ثنائية تكيفية. المناطق الداكنة الصلبة (رؤوس الجداول الملونة، المكتب حول الورقة) تُعامل بعتبة معكوسة ويُحتفظ بحدودها كخطوط.
2. **اكتشاف الجدول وتصحيحه**: أكبر بنية متصلة من الحبر تُعطي أركان الجدول (أو الورقة)؛ إن كانت مائلة يُطبّق تحويل منظور، ثم تُقصّ المساحات غير المهمة.
3. **بنية الجدول**: الخطوط الطويلة المتصلة فقط تُعدّ خطوط تسطير (سطور النص العريض تُستبعد)، تُبنى الشبكة، وتُكتشف الخلايا المدمجة من الفواصل الغائبة.
4. **قراءة النص**: تُقصّ كل خلية إلى أسطر، يُطبّع التباين، وتُقرأ التسميات القصيرة بمتعرّف القوالب، والكلمات بـ Tesseract. يُحتفظ بالنص الخام.
5. **الفهم**: يُصنَّف كل سطر وعمود، يُحدَّد محور الأيام ومحور الحصص وأيهما في الصفوف، تُستنتج التسميات الناقصة من تسلسل الجوار أو من الموقع، وتُحوَّل كل خانة إلى (يوم، حصة، فصل، مادة) مع درجة ثقة.
6. **التحقق**: توحيد أسماء الفصول، حساب جودة الاستيراد، وعرض رسالة واضحة عند عدم القدرة على القراءة، ومحاولة الدوران ١٨٠/٩٠/٢٧٠ تلقائيًا عند الفشل.

## التطوير المستقبلي

النموذج والتخزين مصمّمان لإضافة تسجيل الدخول والمزامنة عبر Supabase، وإشعارات بداية الحصة، وتصدير الجدول صورة/PDF، وأكثر من جدول، دون تغيير الواجهة الحالية.
